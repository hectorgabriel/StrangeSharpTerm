# Lucide, vendored as geometry

## Status

Accepted. Chosen by the project owner; the delivery mechanism is this record's subject.

## Context

The Swift app draws 34 distinct SF Symbols across roughly 90 call sites. SF Symbols
is an Apple font with an Apple licence: it cannot ship inside a Windows app, and
Avalonia has no equivalent. Every one of those glyphs needs a replacement, and the
migration plan asks for a single reviewed pass rather than glyph-by-glyph drift,
because a set chosen one icon at a time ends up looking like several sets.

## Decision

**Lucide**, at version 1.45.0, vendored as Avalonia geometry generated by
`build/icons/generate.py`.

### Not the NuGet package

`Lucide.Avalonia` 0.2.21 exists and restores cleanly, which is misleading: it is
built against **Avalonia 11.3.17**, and this app is on Avalonia 12. Loading it
fails to resolve `Avalonia.Controls 11.3.17` at runtime. Taking a pre-1.0 package
built against a different major version of the UI framework, for icons, is a poor
trade — so the generator takes the upstream SVGs and emits geometry instead.

### How the generator works

Lucide draws with SVG primitives — `rect`, `circle`, `line`, `polyline`, `path` —
and Avalonia's `StreamGeometry` understands only path syntax. Each icon's
primitives are folded into a single path at generation time, and the result is
committed, so a build needs no network.

Two things were easy to get wrong and are now guarded:

- **A leading relative moveto is absolute** per the SVG spec, but only while it is
  the first command of its own path. Concatenated, every icon after the first
  would otherwise be drawn from wherever the previous stroke ended. Rewriting the
  letter alone is not enough: the numbers following a lowercase moveto are
  implicitly *relative* linetos, and an uppercase one makes them absolute.
- **A bounds check** rejects any icon whose path leaves its 24×24 canvas. It
  caught exactly the mistake above while this was being written, which is the
  argument for keeping it.

### Licence

Lucide is **ISC**, not MIT as the migration plan stated; the plan is corrected.
The licence text is vendored beside the icons.

## Consequences

- **Filled variants are gone.** Lucide is a stroke system; SF Symbols' `.fill`
  forms have no counterpart. Where the Swift UI used fill to mean "active" or
  "selected", colour carries that instead.
- **Regenerating needs the network**, the committed output does not.
- Icons are stroked at 2 units on a 24×24 canvas, set once in a style, so a call
  site binds `Data` and nothing else.
